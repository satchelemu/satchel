## Ranked actions
1. **Continue source-backed service work at the actual phone boundary.** Eden [time root](https://github.com/eden-emulator/mirror/blob/943f1fc76087adcfc893fb1ca3aea507df15d004/src/core/hle/service/psc/time/static.cpp), [shared page](https://github.com/eden-emulator/mirror/blob/943f1fc76087adcfc893fb1ca3aea507df15d004/src/core/hle/service/psc/time/shared_memory.h) and [timezone service](https://github.com/eden-emulator/mirror/blob/943f1fc76087adcfc893fb1ca3aea507df15d004/src/core/hle/service/psc/time/time_zone_service.cpp) provide concrete schemas and state relationships. Corroborate ABI with libnx/Atmosphere; inherited Citron/NxEmu copies are not independent firmware evidence. Rule conversion requires real verified timezone data, not merely a host IANA name. No broad service stubs should replace owned state.

2. **Evaluate a bounded native Maxwell compiler component, not a whole emulator transplant.** Eden [Environment](https://github.com/eden-emulator/mirror/blob/943f1fc76087adcfc893fb1ca3aea507df15d004/src/shader_recompiler/environment.h) and [TranslateProgram](https://github.com/eden-emulator/mirror/blob/943f1fc76087adcfc893fb1ca3aea507df15d004/src/shader_recompiler/frontend/maxwell/translate_program.h) feed its SPIR-V backend. Inputs include actual code, constants, texture/layout information, shader header, stage and workgroup/memory state. Proposed future gate: isolate original C ABI, audit common/fmt/sirit dependencies and licenses, bound all environment reads/allocations, then validate original shaders and iPhone output. This translator is native C++ shader processing, separate from guest CPU JIT; no per-game Mac preparation is inherently required. No implementation/performance estimate was validated.

3. **Keep NxEmu’s geometry fallback as a targeted future candidate.** Its [VTG layouts](https://github.com/N3xoX1/nxemu/blob/77e0e87788f40524079b130aa8d8a5fbc3f38b62/src/yuzu_shader_recompiler/vtg_as_compute.h) and [IR pass](https://github.com/N3xoX1/nxemu/blob/77e0e87788f40524079b130aa8d8a5fbc3f38b62/src/yuzu_shader_recompiler/ir_opt/vtg_to_compute_pass.cpp) actually lower vertex/geometry work to compute plus passthrough rasterization. It needs matching buffer ownership, varying layouts and dispatch/draw synchronization; it is not a small standalone switch to enable unsupported Metal geometry shaders.

4. **Study narrowly relevant Metal workarounds only when a fixture demonstrates need.** NxEmu [workarounds](https://github.com/N3xoX1/nxemu/blob/77e0e87788f40524079b130aa8d8a5fbc3f38b62/src/yuzu_video_core/vulkan_common/moltenvk_workarounds.h) includes texel-buffer alignment compensation, attachment overlap and feature admission rules. Its [DontInline patch](https://github.com/N3xoX1/nxemu/blob/77e0e87788f40524079b130aa8d8a5fbc3f38b62/external/moltenvk-patches/0001-honor-spirv-dontinline.patch) changes helper emission. Compared against our actual SPIRV-Cross6c09849fe88c48eaed08413aa022aaa136a3a057, [line12129](https://github.com/KhronosGroup/SPIRV-Cross/blob/6c09849fe88c48eaed08413aa022aaa136a3a057/spirv_msl.cpp#L12117) still force-inlines helpers. The difference is real; an actual need is unproved. Keep official MoltenVK1.4.2/db66022459ffb663aa2b50f6b018bc2e124f5edf. Hidden SPIRV-Cross symbols preclude a casual interposition fix; any future patch needs original MSL/Vulkan compile/output/resource tests and a reviewed rebuild.

5. **Use update/cache provenance ideas without weakening verified content selection.** Eden [PatchManager](https://github.com/eden-emulator/mirror/blob/943f1fc76087adcfc893fb1ca3aea507df15d004/src/core/file_sys/patch_manager.cpp) shows selected update composition. NxEmu [cache identity](https://github.com/N3xoX1/nxemu/blob/77e0e87788f40524079b130aa8d8a5fbc3f38b62/src/yuzu_video_core/shader_profile_identity.h) binds the enabled base/update and cache ABI. Header/size fingerprints are not complete archive integrity. Keep CNMT/content-ID/section validation and reject the known unrelated gallery NSP as a main-title update.

## CPU and architecture limits
No reviewed source supplies a drop-in complete no-JIT iOS CPU. Eden/Citron use Dynarmic on Apple. NxEmu [CPU CMake](https://github.com/N3xoX1/nxemu/blob/77e0e87788f40524079b130aa8d8a5fbc3f38b62/src/nxemu-cpu/CMakeLists.txt) additionally enables Darwin native execution, but it relies on executable guest/runtime-patched mappings and signal machinery. Its [fault handler](https://github.com/N3xoX1/nxemu/blob/77e0e87788f40524079b130aa8d8a5fbc3f38b62/src/nxemu-cpu/nce/arm_nce_darwin.cpp#L388) can skip denied/unknown instructions; our checked interpreter must preserve explicit failure instead.

These renderers process Tegra GPU commands through nvdrv/engines. Satchel currently intercepts original guest NVN functions. NvNflinger is composition/buffer queuing, not an NVN HLE interceptor. A compiler or tested format rule can fit that boundary; importing the entire renderer changes the architecture.

Citron [Vulkan device](https://github.com/citron-neo/emulator/blob/c3aa70f81e15ea97ee85b6a9a71cbf75d370851e/src/video_core/vulkan_common/vulkan_device.cpp) disables robustness features on MoltenVK. Do not transplant that removal into the current checked storage path.

The [installed shader-compiler comparison](Shader-Reuse.md) found that the existing Ryujinx NativeAOT component already contains a broad Maxwell translator. Extend its checked state/resource interface before adding another compiler. A strict graphics-profile experiment is staged separately; no new compiler dependency has been selected or phone graphics compatibility established by this source review.
