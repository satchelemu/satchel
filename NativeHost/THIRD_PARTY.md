Satchel native host notices

The build uses a private source snapshot of nxnative bbc3b73784751d2a706932dc69fd67627e3445d4 with the 34 NX2Apple patches recorded by the Zelda worker. nxnative and NX2Apple are MIT licensed. The build copies their LICENSE into NativeAssets/Notices, alongside libvpx's BSD license and patent notice, stb_vorbis's license (MIT option selected), and bcdec's license (MIT option selected).

The NVN declarations in dm/gfx/nvn/include/nvn.h retain h1k421's MIT notice. The texture layout algorithm in nvn_tex.c retains fincs's deko3d zlib notice. These source notices remain intact in the copied source tree. The build also distributes those notices with the app.

The shared standard font is Noto Sans Regular at notofonts/notofonts.github.io commit 412a7edb2c8c535d1066157e5b17e661fd5591fe, SHA-256 478c558ea716033cd60c03438f628dfa75694dcf6b5f6d505a2f05fd2b4f3823. The upstream compact_font.py fetcher checks that digest. Its embedded font name table contains the SIL Open Font License 1.1 notice and license URL. This replaces upstream's macOS Arial Unicode copy. The Nintendo extension stand-in is generated by the MIT-licensed make_ext_font.py. No operating-system font is copied.

Existing Satchel dependencies and notices remain as supplied by the original target. No GPL code is added. No prepared TOTK modules, RomFS, or e65a4ebd3322 game shader libraries are app bundle resources.

Satchel's Horizon settings and account service overlay adapts command behavior and IPC descriptor layouts from Ryujinx 1.3.3, copyright Ryujinx Team and Contributors, under MIT. The complete notice is retained in NativeHost/services/RYUJINX-LICENSE.txt and distributed as NativeAssets/Notices/Ryujinx-services.txt. Source attribution and scope are recorded in NativeHost/services/README.md.

Satchel controller style selection and update notifications also follow Ryujinx 1.3.3 NpadDevices, with the same retained MIT notice. Controller vibration reuses the pinned MIT engine. Scope and reference paths are in NativeHost/controllers/README.md.
