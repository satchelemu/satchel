Satchel native host notices

The build uses a source snapshot of nxnative f8a5618d5f505a4c0a0bcac7c413872d3a53c009 with the 29 NX2Apple fork patches listed in scripts/deps/upstream/nxnative-queue (25 as published at NX2Apple 8d13135e2a1eec10406f6b486157ec1d2f56eafd, 4 ported to this commit and tracked there). nxnative and NX2Apple are MIT licensed. The build copies their LICENSE into NativeAssets/Notices, alongside libvpx's BSD license and patent notice, stb_vorbis's license (MIT option selected), bcdec's license (MIT option selected), dav1d's BSD 2-Clause license (the AV1 movie decoder the engine compiles in since this pin), the Vulkan headers' license (MIT option selected) and the MacNativeGames MIT license (two routines adapted in the engine's nvn_mtl.m).

The NVN declarations in dm/gfx/nvn/include/nvn.h retain h1k421's MIT notice. The texture layout algorithm in nvn_tex.c retains fincs's deko3d zlib notice. These source notices remain intact in the copied source tree. The build also distributes those notices with the app.

The shared standard font is Noto Sans Regular at notofonts/notofonts.github.io commit 412a7edb2c8c535d1066157e5b17e661fd5591fe, SHA-256 478c558ea716033cd60c03438f628dfa75694dcf6b5f6d505a2f05fd2b4f3823. The dependency lock pins that file and the build checks the digest before copying it (the fork's compact_font.py fetcher left the patch queue at this pin; nothing is fetched at build time). Its embedded font name table contains the SIL Open Font License 1.1 notice and license URL. This replaces upstream's macOS Arial Unicode copy. The Nintendo extension stand-in is generated by the MIT-licensed make_ext_font.py. No operating-system font is copied.

Existing Satchel dependencies and notices remain as supplied by the original target. No GPL code is added. No prepared TOTK modules, RomFS, or 26dc2fa9477c game shader libraries are app bundle resources.

Satchel's Horizon settings and account service overlay adapts command behavior and IPC descriptor layouts from Ryujinx 1.3.3, copyright Ryujinx Team and Contributors, under MIT. The complete notice is retained in NativeHost/services/RYUJINX-LICENSE.txt and distributed as NativeAssets/Notices/Ryujinx-services.txt. Source attribution and scope are recorded in NativeHost/services/README.md.

Satchel controller style selection and update notifications also follow Ryujinx 1.3.3 NpadDevices, with the same retained MIT notice. Controller vibration reuses the pinned MIT engine. Scope and reference paths are in NativeHost/controllers/README.md.

Tier 2 and tier 3 pieces from nxnative (github.com/seedds/nxnative, MIT, same notice), reimplemented or adapted for Satchel. They were taken while the pin was bbc3b737; every upstream commit named below is now part of the pinned engine (f8a5618d), and Satchel's adaptations stay where they differ from it:

- Title-ID architecture check (`scripts/check_architecture.py`): adapted from `dm/tools/tests/test_architecture.py`, upstream commit c7da003c.
- Rumble strength and controller cutoff (`DM_RUMBLE_GAIN`, `DM_RUMBLE_MIN`): read by the pinned engine's `dm/host/haptics_apple.m` and listed in its `dm/games/settings.tsv`; Satchel adds the per-title settings and a live retune hook (`NativeHost/controllers/overlay.py`). No Satchel copy of upstream code.
- iCloud save sync: the pinned engine's `dm/host/save_sync.c` and `dm/ios/Sources/SaveSync.m` (built unchanged; `save_sync.c` gets the session-lifetime overlay `NativeHost/session/save_sync_overlay.py`). `App/CloudSaveFolder.m` adapts the pinned `dm/ios/Sources/CloudSaves.m` bookmark handling. Upstream f9eb12e1 (metadata stream close after write failures) touches only the Mac launcher's save metadata.
- Presented picture shape and the iPhone Duo screen shape (`DM_SCREEN_ASPECT`): the pinned engine now carries both pieces itself (600c0b37, the picture shape report, and 48d79ced, the loader's screen-shape state; Animal Crossing's b6e1f005 uses the same state), so the former `NativeHost/display/picture-shape.patch` is gone. Satchel keeps its own receiver and layout: `front_picture_shape` in `NativeHost/DisplayControls.m` and `SatchelPictureRectAspect` in `NativeHost/DisplayGeometry.h`, adapted from 600c0b37; `NativeHost/display/screen-modes.patch` removes the engine's own receiver and layout so there is one owner. The per-game screen-shape patches of those commits are not ported. Picture Fill (`DM_PICTURE_FIT`, upstream e2fadf22) is deliberately not ported: it is the zoom mode the maintainer removed (GOALS.md G5); see `NativeHost/display/README.md`.
- iPhone Duo layout harness and orientation policy (`Tests/Duo/`): adapted from `dm/ios/tests/duo/` and `dm/ios/tests/test_orientation_policy.py`, upstream e2fadf22 and 600c0b37, including the synthetic `game_profile.h` fixture.
- External display (TV) scene: the pinned engine's `front_ios.m` `DmTVSceneDelegate`, routed by `App/GameOrientation.swift` behind Developer controls. No Satchel copy of upstream code.
- Screen capture services (`caps:su`, `caps:u`, `caps:a`, `caps:c`, `caps:sc`, `caps:ss`): Satchel's IPC layer replaces the engine's session table, so `NativeHost/services/SessionIPC.inc` and `ServiceIPC.inc` mirror the stub sessions of upstream df7fa667.
- Alpha test and logic operation side library (`<key>_bx`, entry points `<entry>_a` and `<entry>_l`): `NativeShaders/Variants.swift` `side()` is a Swift port of the pinned engine's `dm/gfx/tools/dmsh_side.py`, `dmsh_alpha.py` and `dmsh_logic.py` (upstream 13da1c52). `NativeShaders/check-side.py` compares its output byte for byte with `dmsh_side.unit` on the public shader set.
