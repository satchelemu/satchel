# Satchel brand assets

Generated from the app icon's own source, `scripts/app_icon.swift`, with
`swift scripts/app_icon.swift --brand docs/brand`. The mark is original artwork: two tilted
capsules, Ember on the left and a shorter Tide on the right. No Nintendo or Apple assets.

| File | Use |
|---|---|
| `satchel-avatar-1024.png` | GitHub profile or organization picture (Settings, Profile picture). Survives the circular crop. |
| `satchel-social-preview-1280x640.png` | Repository social preview (repository Settings, Social preview). GitHub's recommended size. |
| `satchel-mark-1024.png` | The mark alone on a transparent background, for READMEs and slides. |
| `satchel-mark.svg` | The mark as vectors, for anything that scales. |

The assets are MIT licensed with the rest of the repository. Use them to refer to Satchel;
do not use them to suggest that something else is Satchel.
